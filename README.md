## 🚀 The Weekend Dadz AI-Powered Merch Experience

This repository contains the source code for the official **Weekend Dadz** e-commerce PWA, built with React and powered by the Gemini & Imagen APIs. It's designed to be more than a store—it's a creative partner for dadz everywhere.

### Core Featurez ✨

* **🤖 AI Weekend Planner & Core Memory Merch™:** Don't know what to do this weekend? Tell our AI about your crew, vibe, and the weather. It will generate:
    * A full weekend itinerary.
    * A unique design concept for a "Core Memory" t-shirt to commemorate the occasion.
    * An on-demand, AI-generated image of that exact t-shirt!

* **🎨 AI Design Lab:** Every product is a canvas. Pick any item from our collections, give the AI your wild ideas, and generate a completely unique, randomized design on the spot. No two designs are ever the same.

* **👨‍👧‍👦 The Dad-abase Personas:** Shop collections tailored to every kind of Weekend Dad.

### Getting Started Locally

Ready to dive in? Follow these simple steps to get the app running on your local machine.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Sourcesiri-kamelot/weekenddadz.com.git](https://github.com/Sourcesiri-kamelot/weekenddadz.com.git)
    cd weekenddadz.com
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    The app should now be running on `http://localhost:3000`!
